# Original Soulbound creature art

Created for Mark's Soulbound project in Blender 4.3.2 on 2026-10-10.
No downloaded third-party meshes, paid generation outputs or image textures.
Source mesh utilities/palette derive from the project's previously approved
Soulbound specialist pack. The six designs were approved before animation.

Runtime exports contain rigid-joint IDs in TEXCOORD_1.x. Do not replace them
with the skinned portable GLBs without changing the renderer. See
`docs/creatures/README.md` for the coordinate, animation and integration contract.
Editable Blender masters, original static exports and portable animated GLBs
are retained in the companion Soulbound Animated Creatures Integration pack.
